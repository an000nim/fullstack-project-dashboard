# Установка и запуск

## Требования

- Node.js 22.12 или новее и npm.
- Docker Desktop с Docker Compose.

## Запуск с Docker

1. Откройте терминал в корневой папке проекта. Запустите Docker Desktop.
2. Создайте файл настроек и запустите базу:

   ```sh
   cp .env.example .env
   docker compose up -d db
   docker compose ps
   ```

   Дождитесь состояния `healthy`. При первом запуске база и начальные данные создаются автоматически из `init-db.sql`.

3. В этом же терминале установите зависимости сервера и запустите его:

   ```sh
   cd server
   npm ci
   npm run dev
   ```

4. Откройте второй терминал в корневой папке проекта и запустите клиент:

   ```sh
   cd client
   npm ci
   npm run dev
   ```

5. Откройте http://127.0.0.1:5173.

Сервер использует порт `3001`, клиент — `5173`, PostgreSQL в Docker — `5433`. Эти порты должны быть свободны.

При последующих запусках повторять `cp .env.example .env` и `npm ci` не нужно. Достаточно запустить Docker Desktop, выполнить `docker compose up -d db` из корня проекта и `npm run dev` в папках `server` и `client` в отдельных терминалах.

## Остановка

В терминалах сервера и клиента нажмите `Control + C`. Для остановки базы Docker выполните из корня проекта:

```sh
docker compose stop
```

Данные базы сохраняются после остановки.
